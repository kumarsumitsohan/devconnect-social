# DevConnect Social

A social media dashboard for developers to share projects, like, comment, and connect.  
Built with **Node.js, Express, MongoDB, and a static HTML/CSS/JS frontend**, deployed on **Vercel** using serverless functions.

## Quick Start

1. Create a MongoDB Atlas cluster and get your connection string.
2. On Vercel, set environment variables:

- `MONGO_URI` = your MongoDB connection string
- `JWT_SECRET` = a strong secret key

3. Deploy this repo to Vercel (GitHub import or `vercel` CLI).

The app will be available at your Vercel URL, for example:

- Frontend: `https://your-app.vercel.app/`
- API: `https://your-app.vercel.app/api/posts`
